# Esercizio 2 — Gestione studenti

Programma da riga di comando per gestire una lista di studenti in memoria.

## Obiettivo
Permettere all’utente di:
- aggiungere studenti (nome, cognome);
- elencare gli studenti in ordine alfabetico;
- cercare per nome o cognome (match parziale, case-insensitive).

Il programma utilizza esclusivamente **liste, cicli, condizioni e funzioni** (o oggetti), senza database o file esterni.

---

## Requisiti
- Python 3.10+
- Nessuna libreria esterna necessaria per l’esecuzione del programma
- (Opzionale) Per la documentazione: `sphinx`, `numpydoc`, `sphinx-rtd-theme`
